# 🎬 Movie Rating Analysis using Python & Google Colab

An exploratory data analysis project focused on analyzing **movie ratings and related attributes** using Python in Google Colab. The project works with a dataset containing **650 movies** and uses data cleaning, statistical analysis, visualization, and insight generation to understand movie rating patterns.

---

## 📌 Project Overview

This project performs an end-to-end analysis of movie ratings using **Python, Pandas, NumPy, Matplotlib, and Seaborn**.

The analysis explores movie rating distributions, identifies highly rated movies, examines patterns within the dataset, and presents the findings through visualizations.

The complete analysis was performed using **Google Colab**.

---

## 🎯 Objectives

* 🧹 Clean and prepare the movie dataset
* 📊 Perform Exploratory Data Analysis (EDA)
* ⭐ Analyze movie rating distributions
* 🎬 Identify highly rated and low-rated movies
* 🔍 Explore relationships between different movie attributes
* 📈 Create meaningful visualizations
* 💡 Generate useful insights from the analysis
* 📄 Present findings through a visual analysis report

## 🚀 How to Run the Project

### Option 1 — Google Colab

1. Open the `Task6.ipynb` notebook.
2. Upload the dataset:
   `movie_ratings_analysis_650_movies.csv`
3. Open the notebook in **Google Colab**.
4. Run the cells sequentially.
5. Review the generated visualizations and insights.

### Option 2 — Jupyter Notebook

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Then open:

```bash
jupyter notebook
```

Run `Task6.ipynb`.
